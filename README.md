# Math Quiz Game — C++

A console-based Math Quiz Game built with C++ that allows players to customize their quiz, choose difficulty levels, practice different arithmetic operations, and track their performance through a final results summary.

## Features

- **Custom Quiz Length:** Choose how many questions to answer.
- **Multiple Difficulty Levels:** Select Easy, Medium, Hard, or Mix.
- **Four Arithmetic Operations:** Practice Addition (+), Subtraction (-), Multiplication (*), and Division (/).
- **Mixed Quiz Modes:** Combine randomly selected difficulty levels and arithmetic operations.
- **Random Question Generation:** Generate questions using random numbers based on the selected difficulty.
- **Instant Answer Feedback:** Know immediately whether your answer is correct or incorrect.
- **Correct Answer Display:** View the correct answer whenever you answer incorrectly.
- **Performance Tracking:** Keep track of correct and incorrect answers throughout the quiz.
- **Final Results Summary:** Review the total number of questions, selected difficulty, operation type, and your results.
- **Pass/Fail Evaluation:** Receive a final result based on your correct and incorrect answers.
- **Console Color Feedback:** The console color changes according to the final result.
- **Replay Option:** Start another round without restarting the application.
- **Input Validation:** Handle invalid numeric input in the quiz setup and answer entry.

## Difficulty Levels

| Level | Description |
|---|---|
| Easy | Random numbers from 1 to 20 |
| Medium | Random numbers from 20 to 50 |
| Hard | Random numbers from 50 to 100 |
| Mix | Random difficulty levels and numbers from 1 to 100 |

## How to Run

1. Clone or download this repository.
2. Open the Visual Studio project or solution, if available.
3. Build the project.
4. Run the application in the console.
5. Choose the number of questions, difficulty level, and arithmetic operation.
6. Answer the questions and review your final results.
